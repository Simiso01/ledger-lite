# Ledger Lite

A personal expense tracker that runs in the browser. Amounts are in South African rand. Data stays in `localStorage` on your machine.

## What you can do

- Record income and expenses
- Set a budget for the month you are viewing
- See income, spending, and what is left
- Remove a transaction
- Load sample data to try the layout, then clear it

## Run it

Open `index.html` in a browser. No install step.

## Tech

HTML, CSS, and JavaScript. No framework and no build step.
